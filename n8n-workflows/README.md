# 당근 로컬 SEO 소식글 자동화 · n8n 워크플로우

당근마켓 비즈프로필 로컬 SEO 콘텐츠 대행 운영을, 블랙박스인 "당근 자동 실행앱"의
**앞단(입력 준비)과 뒷단(정리·보고)** 을 감싸서 자동화합니다.
알림 채널은 **텔레그램**입니다.

> 당근마켓은 공개 API가 없고 자동실행앱을 외부에서 제어할 수 없기 때문에,
> 앱 조작(2·3·4·5·7단계)은 사람이 하고, 그 **주변 반복노동만** n8n이 처리합니다.

## 워크플로우 구성

| 파일 | 역할 | 대응 루틴 |
|---|---|---|
| `WF-1_키워드_브랜딩_프레임워크_생성기.json` | 업체정보 입력 → Claude가 키워드·필수기재(상/하단)·금기어 생성 → 시트 저장 | 1단계 대체 + 2·4단계 입력값 준비 |
| `WF-2_소식글_로거.json` | 생성된 제목/본문 붙여넣기 → 시트 기록 + 대표님 텔레그램 초안 발송 | 6·7단계 |
| `WF-3_주간_보고_봇.json` | 매주 자동 집계 → 텔레그램 주간 보고 | 8단계 |

각 파일 안의 **노란 스티키 노트**에 노드별 설정 방법이 적혀 있습니다.

## 불러오는 법 (복사/붙여넣기)

1. n8n 접속 → 우상단 **… → Import from File**(파일 선택) 또는
   새 워크플로우에서 캔버스 클릭 후 **Ctrl+V** 로 JSON 붙여넣기
2. 빨간 노드(자격증명 미설정)를 열어 아래 자격증명 연결
3. `여기에_대표님_텔레그램_CHAT_ID` 를 실제 chat_id로 교체

## 준비물 (자격증명 3가지)

| 자격증명 | 만드는 곳 | 쓰는 노드 |
|---|---|---|
| **Header Auth** (`x-api-key` = Anthropic API 키) | n8n Credentials | WF-1 Claude 호출 |
| **Google Sheets OAuth2** | Google Cloud + n8n | WF-1/2/3 시트 |
| **Telegram Bot** (BotFather 토큰) | @BotFather | WF-1/2/3 알림 |

### 텔레그램 chat_id 얻는 법
1. @BotFather 로 봇 생성 → 토큰 확보
2. 대표님이 그 봇에게 아무 메시지 전송
3. `https://api.telegram.org/bot<토큰>/getUpdates` 열면 `chat.id` 확인

## 구글 시트 준비 (탭 2개)

같은 스프레드시트에 아래 두 탭과 1행 헤더를 만들어 주세요.

**`고객사마스터` 탭 헤더**
```
생성시각 상호명 업종 지역 핵심키워드 서비스키워드 금기어 Primary Secondary LongTail Regional Additional 필수기재상단 필수기재하단 해시태그 리포트
```

**`소식글` 탭 헤더**
```
기록시각 업체명 세트 제목 본문 발행예정일 발행예정시간 상태
```

기본 스프레드시트 ID는 담당자 시트(`1iSLUOQ...VYZBQ`)로 지정되어 있습니다.
다른 시트를 쓰려면 각 Google Sheets 노드에서 문서/탭을 다시 선택하세요.

## 전체 운영 흐름

```
[신규 고객사]  WF-1 폼 입력 ──► 키워드/필수기재/금기어 생성 ──► 시트 저장
                                        │
                                        ▼ (값 복붙)
              당근 자동실행앱 2~5단계(사람)  ──► 소식글 자동생성·승인예약
                                        │
                                        ▼ (제목/본문 복사)
[검수]         WF-2 폼 입력 ──► 시트 기록 + 대표님 텔레그램 초안
                                        │
                                        ▼
[운영앱 7단계 일괄 승인(사람)]           
                                        │
                                        ▼
[매주 금 18시] WF-3 ──► 시트 집계 ──► 텔레그램 주간 보고 자동 발송
```

## 참고 · 한계

- 개인 카카오톡 자동 전송은 공식 지원되지 않아 **텔레그램**으로 구성
