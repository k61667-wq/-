# 당근 AI CMS 운영 자동화 · n8n 워크플로우

`당근 AI CMS`(karrot.evenit.co.kr · 클라우드 대시보드 + 발행PC 로컬 실행앱) 운영 루틴에서,
앱이 못 하는 **앞단(키워드/브랜딩 준비)** 과 **뒷단(검수요청·발행보고)** 을 자동화합니다.
알림 채널은 **텔레그램**입니다.

> 앱에 공개 API가 없어 앱 화면 조작(고객사 등록·캠페인 생성·승인예약)과 발행PC 물리작업은 사람이 수행합니다.
> n8n은 그 주변 반복노동만 제거합니다.

## 워크플로우 3종

| 파일 | 역할 | 대응 루틴 |
|---|---|---|
| `WF-1_키워드_브랜딩_프레임워크_생성기.json` | 업체정보 입력 → Claude가 **핵심키워드·서브키워드·말투톤·필수기재(상/하단)·불포함키워드** 완성형 생성 → 시트 저장 | 1단계 대체 + 2·4단계 입력값 준비 |
| `WF-2_소식글_초안_로거.json` | 제목/본문 붙여넣기 → 구글시트 기록 + 대표님 텔레그램 검수요청(시트링크 포함) | 6단계 |
| `WF-3_발행현황_CSV_리포터.json` | 앱 `발행 현황`의 **CSV 업로드** → 시트 upsert(중복제거) → 주간 보고 자동 발송 | 8단계 |
| `WF-4_소식글_자동생성기.json` | 비즈프로필 정보 입력 → AI가 **시리즈 컨셉 + 소식글 여러 개** 자동 생성 → 시트 저장 + 대표님 텔레그램 | 소식글 초안 생성 |
| `WF-5_소식글_검수알림봇.json` | 프로그램 연동 시트에 **새 초안 행 추가 시** → 대표님 텔레그램 검수요청 (자동) | 6단계 (연동판) |
| `WF-6_주간_발행보고봇.json` | 프로그램 연동 시트 **직접 읽어** 주간 발행 실적 자동 보고 (CSV 수동 불필요) | 8단계 (연동판) |

> ⭐ **개발사 양방향 연동(2026-07) 반영**: `소식글 (프로그램)` 탭이 프로그램과 1분 주기 자동 동기화되면서
> **WF-5/WF-6가 WF-2/WF-3를 대체**합니다. AI 초안이 시트에 자동 추가되고(컨펌 칸에서 승인/반려), 발행결과가 자동 기록됩니다.
> 연동 시트 컬럼: `발행일 · 제목 · 게시글 본문 · 당근 URL · 사진첨부 · 업체 · 컨펌 · ID · 발행상태`
> 연동 시트 ID: `17Eov1bJTrbHpSVanCBsAWg-L1s4H0Pa58PDVeeITEKk`

### 현재 권장 구성
- **유지**: WF-1(키워드 준비) · WF-4(소식글 초안 생성) · **WF-5(검수 알림)** · **WF-6(주간 보고)**
- **은퇴**: WF-2(초안 수동입력) · WF-3(CSV 수동업로드) — 개발사 연동이 대체

각 워크플로우 캔버스의 **노란 스티키 노트**에 노드별 설정법이 있습니다.

## WF-1 출력 → 앱 필드 매핑 (1:1)

| WF-1 출력 | 당근 AI CMS 입력칸 |
|---|---|
| 핵심키워드 | 고객사 관리 · **핵심 키워드** |
| 서브키워드 | 고객사 관리 · **추천 서브키워드** |
| 말투톤 | 고객사 관리 · **말투 & 톤** |
| 필수기재상단 / 필수기재하단 | 자동 캠페인 · **필수기재내용 상단 / 하단** |
| 불포함키워드 | 자동 캠페인 · **불포함 키워드** |

## 불러오기 (복사/붙여넣기)

1. n8n → **… → Import from File** 로 JSON 선택 (또는 파일 내용 복사 후 캔버스 `Ctrl+V`)
2. 빨간 노드(자격증명 미설정)를 열어 자격증명 연결
3. `여기에_대표님_텔레그램_CHAT_ID` 를 실제 chat_id로 교체

## 준비물 (자격증명 3가지)

| 자격증명 | 만드는 곳 | 쓰는 곳 |
|---|---|---|
| **Header Auth** (`x-api-key` = Anthropic API 키) | n8n Credentials | WF-1 |
| **Google Sheets OAuth2** | Google Cloud + n8n | WF-1/2/3 |
| **Telegram Bot** (BotFather 토큰) | @BotFather | WF-1/2/3 |

**텔레그램 chat_id**: BotFather로 봇 생성 → 대표님이 봇에 메시지 →
`https://api.telegram.org/bot<토큰>/getUpdates` 에서 `chat.id` 확인.

## 구글 시트 탭 3개 (같은 스프레드시트)

기본 시트 ID는 담당자 시트(`1iSLUOQ...VYZBQ`)로 지정돼 있습니다.

**`고객사마스터`** (WF-1)
```
생성시각 상호명 업종 지역 말투톤 핵심키워드 서브키워드 불포함키워드 필수기재상단 필수기재하단 Primary Secondary LongTail Regional Additional 해시태그 리포트
```

**`소식글초안`** (WF-2)
```
기록시각 업체명 세트 제목 본문 발행예정일 발행예정시간 상태
```

**`발행현황`** (WF-3 · CSV 컬럼과 동일)
```
client profile account publishedAt title url doneJobId bodyPreview
```

**`소식글생성`** (WF-4)
```
생성시각 업체명 지역 컨셉 순번 세트 제목 본문 핵심키워드 해시태그 링크
```
> `doneJobId` 기준으로 upsert되어, CSV를 매번 통째로 올려도 중복 없이 누적됩니다.

## 전체 운영 흐름

```
[신규 고객사]  WF-1 폼 → 키워드/말투톤/필수기재/불포함키워드 생성 → 시트
                        │  (값 복붙)
                        ▼
        당근 AI CMS 고객사관리·자동캠페인 2~5단계(사람) → 소식글 자동생성
                        │  (제목/본문 복사)
                        ▼
[검수요청]     WF-2 폼 → 구글시트 기록 + 대표님 텔레그램(시트링크)
                        ▼
        대표님 시트 검수 → 앱에서 7단계 일괄 승인(사람)
                        ▼
[주간보고]     앱 발행현황 → [CSV] 내보내기 → WF-3 업로드
                        → 시트 정리 + 주간 실적 보고 자동 발송
```

## 한계 (자동화 불가 · 정직하게)

- 🔴 **2·3·4·5단계**(고객사 등록·매장연결·캠페인 생성·승인예약) — 앱 API 부재로 사람이 앱에서 수행
- 🔴 **발행PC 물리작업** — 실행앱 켜기, 당근 본인확인, 구글 로봇확인
- 🟡 **7단계 승인** — 판단 필요, 앱에서 클릭
- 개인 카카오톡 자동전송 미지원 → **텔레그램**으로 구성
