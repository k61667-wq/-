# 뉴스포스트 운영 마스터 — 시트 구조 정의서

스프레드시트 이름: **뉴스포스트 운영 마스터**
탭 7개. 열 색 규칙: **흰색 = 사람 입력 / 회색 = 자동(수식·스크립트, 시트 보호 필수)**

> 회색 열에 시트 보호를 걸지 않으면 "Master는 바뀌었는데 작성시트는 옛날 값"인 상태가 조용히 생깁니다.
> 필수기재 하단에서 이게 발생하면 곧바로 법적 리스크입니다. 보호는 선택이 아니라 필수입니다.

## 01_Company_Master (업체 마스터)

모든 업체 정보의 **유일한 원본**. 다른 탭은 여기를 읽기만 합니다.

## 06_대시보드

**입력 셀이 하나도 없는 탭입니다.** 전부 수식.

### 업체별 (1행 = 1업체)

| 열 | 지표 | 계산 |
|---|---|---|
| A | 업체명 | Master |
| B | 상태 | Master |
| C | 목표 | Master.V |
| D | 완료 | `COUNTIFS(05!C:C, id, 05!AC:AC,"등록완료")` |
| E | 진행률 | D/C |
| F | 기대진행률 | `(TODAY()-계약시작)/(계약종료-계약시작)` |
| G | **페이스** | `E-F` → −10%p 미만이면 🔴지연 |
| H | 최근발행일 | `MAXIFS(05!AE, 05!C, id)` |
| I | **공백일수** | `TODAY()-H` → **7 초과 시 🔴** (노출 후보군 이탈) |
| J | 잔여콘셉트 | 04 미사용 카운트 → **5 미만 🟡** |
| K | 초대상태 | 03 |
| L | 계정상태 | 02 (잠김·미배정이면 🔴) |
| M | 검수대기 | 상태별 COUNTIFS |
| N | 정체(3일+) | 최종수정일 D+3 & 미완료 |

### 전체 요약 (상단 고정)

이번 달 발행 건수 / 목표 대비 / 검수 대기 총건 / 3일 이상 정체 / 공백 7일 초과 업체 수 / 잔여 콘셉트 부족 업체 수 / 계정 경고 수
