# 당근(당근마켓) 로컬 마케팅 제안서 — 업종별

> **사용 안내(대행사 내부)**: 이 문서는 고객사 업종에 맞춰 편집해 제출하는 제안서 **템플릿**입니다.
> `[○○동]`, `[매장명]`, 금액·조건 예시는 고객사 상권·마진에 맞춰 확정하세요.
> 금액·KPI는 **보장 수치가 아닌 벤치마크 방향**이며, 표시광고법·업종별 규제(의료·교육)·당근 정책 기준으로 발행 직전 재검수합니다.

---

## 1. 왜 당근인가

당근은 **동네 반경 기반**으로 노출되는 하이퍼로컬 플랫폼입니다. 실제로 걸어오거나 차로 5~10분 안에 방문 가능한 **근거리 잠재고객**에게 광고가 도달하므로, 로컬 오프라인 매장·서비스업에 전환 효율이 높습니다.

**핵심 전환 퍼널**
```
당근 광고(유입) → 비즈프로필(랜딩·신뢰) → 쿠폰·소식·문의(전환) → 방문 → 후기 → 단골(재노출 자산)
```
- 비즈프로필은 광고의 **랜딩 페이지**입니다. 광고만 켜고 프로필이 부실하면 유입이 샙니다.
- **단골 수 = 재노출 자산**입니다. 당근 소식은 단골에게 알림으로 도달하므로, 모든 쿠폰·이벤트는 "단골 맺기"를 유도 장치로 설계합니다.

## 2. 제공 서비스 (2단 구성)

| 구성 | 담당 | 내용 |
|---|---|---|
| **① 비즈프로필 세팅·운영** | 랜딩/전환 | 개설·인증, 사진·소개글 최적화, 소식(피드) 운영, 쿠폰·단골 설계, 후기 관리 |
| **② 당근 광고 운영** | 유입/성과 | 캠페인 설계(지역·타겟·예산), 소재 제작·A/B, 성과 리포트, 예산·소재 최적화 |

> 두 축을 **하나의 퍼널로 연동**합니다. 성과가 낮을 때는 "유입(소재/타겟) vs 랜딩(프로필) vs 전환(오퍼/응대)" 중 어디서 새는지 진단해 순서대로 개선합니다.

# 업종별 제안

각 업종은 **① 왜 당근 · ② 비즈프로필 세팅 · ③ 소식·쿠폰·단골 · ④ 광고 캠페인(타겟·예산·소재·KPI) · ⑤ 최적화**로 구성됩니다.

## 1) 음식점·카페

**① 왜 당근** — "근처 뭐 먹지 / 동네 카페" 수요가 즉시 방문으로 이어지는 고전환 업종. 도보권 손님에 직접 도달.

**② 비즈프로필 세팅**
- 카테고리: 음식점(한식/일식/양식 등 세부) 또는 카페·디저트 — 세부 지정 필수
- 대표키워드: `[○○동] 브런치카페`, `[○○역] 혼밥`, `단체석 고깃집`, `포장·배달` + 시그니처 메뉴명
- 사진: 대표=시그니처 메뉴 클로즈업 / 필수=대표메뉴 3~5컷·내부·외관간판·메뉴판(가격 공개)·주차입구
- 소개글 필수: 영업시간·브레이크·라스트오더, 주차, 예약/포장/배달, 대표메뉴·가격대, 위치 앵커, 좌석·노키즈 정책

**③ 소식·쿠폰·단골**
- 소식: 신메뉴/시즌메뉴, 한정수량 안내, 영업시간 변경 공지, 재료·조리 원칙, 단골 전용 서비스
- 첫방문 쿠폰: "당근 보고 첫 방문 시 음료 1잔 무료" 또는 "1만원 이상 주문 시 사이드 증정"
- 단골 락인: 단골 맺기 시 음료 업사이즈 + "5회 방문 시 시그니처 무료" 스탬프 / 한산한 평일 오후 "단골 10%"

**④ 광고 캠페인**
- 목표: 매장 방문·쿠폰 사용(핵심지표=쿠폰 사용률·단골 증가)
- 타겟: 반경 1.5~3km(유동상권 좁게/배후상권 넓게), 메뉴 성격별 연령 조정, 식사 직전 시간대(11시·17~18시) 가중
- 예산: **월 20~50만원** 시작(객단가 낮아 "쿠폰 사용당 원가"로 관리, 신규오픈 첫 1~2달 상단)
- 소재: 시그니처 클로즈업+쿠폰 문구 / 카피 예) "○○동 새로 생긴 [메뉴], 첫 방문 시 음료 서비스" · "걸어서 3분, 오늘 저녁 [시그니처] 쿠폰"
- KPI(범위): CTR 1~2%대, 쿠폰 다운당 수백~1천원대(실사용은 그 몇 배) → 방문당 원가로 객단가 대비 판단

**⑤ 최적화 순서** 소재(메뉴·쿠폰 A/B) → 랜딩(메뉴판·주차정보) → 타겟(반경·시간대) → 예산(피크타임 집중)

## 2) 미용실·네일·에스테틱 (뷰티)

**① 왜 당근** — "동네에서 오래 다닐 단골 가게" 수요와 정확히 일치. 결과가 사진으로 증명되고 예약제라 문의→예약 전환이 명확.

**② 비즈프로필 세팅**
- 카테고리: 미용실/헤어, 네일·속눈썹, 피부·에스테틱, 왁싱 등 정확히
- 대표키워드: `[○○동] 남성컷`, `뿌리염색`, `젤네일`, `속눈썹 연장`, `1인샵/프라이빗`
- 사진: 대표=시술 결과 베스트컷(**고객 서면 동의 필수, 초상권**) / 시술별 포트폴리오·위생관리·디자이너 소개·가격표. before/after는 조명·보정 동일 조건, 과장 금지
- 소개글 필수: 예약 방법, 시술별 가격·소요시간, 주차, 디자이너 전문분야, 위생 정책, 위치 앵커

**③ 소식·쿠폰·단골**
- 소식: 시즌 트렌드 제안, 신규 시술, 홈케어 팁, 예약 여유 시간대, 디자이너 소개
- 첫방문 쿠폰: "당근 첫 방문 시 컷 20% / 첫 네일 1만원 할인"
- 단골 락인: 단골 맺기 시 앞머리컷·영양팩 무료 / "염색 4회 선결제 시 1회 무료" / "4주 내 리터치 재방문 10%" / 생일 쿠폰

**④ 광고 캠페인**
- 목표: 예약 문의(채팅·전화), 첫 방문 쿠폰 사용 → 재방문 사이클(4~6주) 관리
- 타겟: 반경 1.5~3km(근거리 재방문 업종이라 좁게), 시술별 20~40대 여성 가중(바버샵은 남성)
- 예산: **월 30~70만원**(시술 객단가·재방문 LTV 커서 신규 1건 가치 큼, 1인샵 하단)
- 소재: 결과 이미지("시술 예시" 표기)+첫방문 혜택 / 카피 예) "○○동 첫 방문 [펌/컬러] ○○% 할인 — 예약 채팅" · "네일 리터치 주기 되셨죠? 이번 주 예약 가능"
- KPI(범위): CTR 1~2%대, 채팅문의당 수천~1만원대(객단가로 감내 가능), 신규 1건의 재방문 가치까지 반영

**⑤ 최적화 순서** 랜딩(메뉴·가격·예약 명확화 — 가격 불투명이 이탈 1순위) → 소재(결과·혜택) → 타겟(시술별 세분) → 예산(예약 몰리는 요일)

## 3) 헬스장·필라테스·PT (피트니스)

**① 왜 당근** — 접근성이 등록의 핵심 변수. 도보·차량 근거리 노출이 곧 등록 전환.

**② 비즈프로필 세팅**
- 카테고리: 헬스장, 필라테스·요가, PT, 크로스핏 등
- 대표키워드: `[○○동] 필라테스`, `1:1 PT`, `여성전용 헬스`, `체험수업`, `직장인 아침운동`
- 사진: 대표=넓고 청결한 공간/기구 전경 / 시설·샤워탈의실·주차·프로그램·강사 프로필(자격·경력)·가격. 청결·환기 강조
- 소개글 필수: 회원권 종류·가격, 운영시간(24h 여부), 체험/1일권, 주차·샤워, 강사 자격, 위치 앵커

**③ 소식·쿠폰·단골**
- 소식: 무료 체험/오픈 이벤트, 운동 팁, 회원 변화 사례(**본인 동의+개인차 안내**), 그룹수업 잔여석, 신규 기구
- 첫방문 쿠폰: "무료 1회 체험 수업" / "PT 첫 등록 시 1회 추가 무료" — 체험이 등록 전환 최강 장치
- 단골 락인: 친구 추천 시 양쪽 1개월 연장, 장기권 할인, 출석 챌린지, 만료 7일 전 단골 알림

**④ 광고 캠페인**
- 목표: **체험·상담 예약**(피트니스는 "체험→등록" 2단 퍼널이라 체험 예약이 실질 목표)
- 타겟: 반경 2~4km(통근·거주 동선), 종목별 연령·성별, 성수기(1월·5~6월·환절기) 가중
- 예산: **월 40~100만원**(등록 객단가 높아 문의당 여유 큼, 경쟁 밀집 → 시즌 집중)
- 소재: 청결 시설·소규모 수업·트레이너 전문성+무료체험 명시("몇 주 만에 몇 kg" 등 결과 보장 금지) / 카피 예) "○○동 필라테스 무료체험 1회 — 채팅으로 시간만" · "PT 첫 상담 무료, 목표부터 같이"
- KPI(범위): CTR 1~2%대, 체험 예약당 수천~수만원(경쟁·시즌 편차), 최종 ROI는 체험→등록 전환율이 결정

**⑤ 최적화 순서** 랜딩·응대(체험 예약 방법·상담 응답속도) → 소재(무료체험 오퍼·시설) → 타겟(프로그램별) → 예산(성수기 집중)

## 4) 보습학원·공부방·교습소 (교육)

**① 왜 당근** — 학원 탐색은 철저히 "우리 동네·우리 단지" 반경. 동네 신뢰 기반 업종이라 궁합이 좋음.

**② 비즈프로필 세팅**
- 카테고리: 학원·교습소, 공부방, 과목별(수학/영어/국어/논술 등)
- 대표키워드: `[○○동] 초등수학`, `중등영어 내신`, `1:1 관리형`, `[○○초] 인근 공부방`
- 사진: 대표=밝고 정돈된 강의실 또는 원장 프로필 / 강의실·자습공간·교재·시간표·소규모 정원·상담실(**학생 얼굴은 학부모 동의 필수**)
- 소개글 필수: 대상 학년·과목, 반 편성·정원, 수업 요일·시간, 원비 안내(학원법상 교습비 게시 원칙), 원장 이력, 등하원 안전, 위치 앵커, 상담 예약

**③ 소식·쿠폰·단골**
- 소식: 특강·방학특강 모집, 학습법 팁, 신규 반 개설·잔여 정원, 교육 정보(개정 교육과정 등 사실). 성적 인증은 개인정보·과장 리스크로 신중
- 첫방문 쿠폰: "무료 학습 진단테스트+1:1 상담" / "첫 등록 시 교재비 면제" / "1주 무료 체험"
- 단골 락인: 형제·친구 추천 등록 양쪽 할인, 3개월 선납 할인, 방학특강 단골 우선 접수

**④ 광고 캠페인**
- 목표: **상담·레벨테스트 예약, 설명회 신청**(학부모 의사결정 신중 → 리드 확보)
- 타겟: 반경 1.5~3km(등하원·픽업 거리, 단지 밀집 우선), 학부모=30대 후반~50대, 자녀 학년별 조정, 신학기(2~3월·8~9월) 가중
- 예산: **월 30~60만원**(수개월 수강료 LTV 커서 리드당 여유, 상권 좁아 과다 예산은 피로도 → 시즌 집중형)
- 소재: 강사 이력·커리큘럼·소수정예·관리 강조("성적/등급 상승 보장" 등 결과보장·최상급 금지) / 카피 예) "○○동 초등 [과목] 신학기 반 모집 — 무료 레벨테스트" · "우리 아이 [과목] 어디부터? 무료 학습상담"
- KPI(범위): CTR 1%대 내외(정보 탐색형), 상담·테스트 예약당 수천~수만원 → 상담→등록률을 함께 관리

**⑤ 최적화 순서** 랜딩(커리큘럼·시간표·강사·수강료) → 소재(무료 테스트·설명회, 대상 학년) → 타겟(학년별 학부모·단지) → 예산(신학기·방학 집중)

## 5) 병원·의원·한의원 (로컬 의료)

> ⚠️ **의료광고 규제**: 치료경험담·환자 후기 활용 제한, 과장·비교·최상급·효과 보장 금지, 비급여 진료비 정확 고지. 급여 진료 본인부담금 임의 할인·면제 금지(국민건강보험법). **사전 심의 대상 여부 반드시 확인.**

**① 왜 당근** — "집·회사 근처 다닐 병원" 근거리 수요가 명확. 규제가 강해 **정보 제공형 신뢰 구축**이 전환의 핵심.

**② 비즈프로필 세팅**
- 카테고리: 병원·의원(진료과목별: 내과/정형외과/피부과/치과/한의원 등)
- 대표키워드: `[○○동] 내과`, `[○○역] 정형외과`, `야간진료`, `일요일 진료`, `한방 교통사고`(사실 기반 진료범위 위주)
- 사진: 대표=외관+간판 또는 청결한 접수·대기 공간 / 진료실·검사장비·위생환경·의료진 프로필(전문의 자격, 사실만)·주차(환자·진료장면은 규정 준수 제한적)
- 소개글 필수: 진료과목, 진료시간·야간/주말/점심, 예약·접수 방법, 주차, 의료진 약력, 위치 앵커, 비급여 항목은 정확한 금액 고지

**③ 소식·쿠폰·단골**
- 소식: 진료시간·휴진·명절 진료 안내(헛걸음 방지), 계절 건강정보, 신규 장비·진료과목, 예방접종·검진 시즌, 이용 안내. 치료효과·환자 사례 노출 지양
- 쿠폰: 급여 진료는 할인 대상 아님. 비급여만 법적 범위 내 신중히. 기본은 **"채팅 간편 예약" 등 편의 제공형**
- 단골 락인: 예방접종·검진 시기 알림, 정기 진료 리마인더(금전 유인 아닌 정보·관계형 리텐션)

**④ 광고 캠페인**
- 목표: 예약·진료 문의(전화·채팅), 진료시간·위치 확인 후 방문
- 타겟: 반경 2~4km(진료과별), 소아과=30~40대 학부모/정형·통증=40~60대/여성의원=여성 등, 진료 시작 전·평일 오전 가중
- 예산: **월 30~80만원**(재진 LTV 큼, 단 심의·표현 제약으로 소재 리스크 관리 감안해 보수적 시작)
- 소재: 진료과목·시간·위치·주차 등 **사실 정보 중심**, 청결 시설·의료진(치료효과 보장·유인·최상급·비교 금지) / 카피 예) "○○동 [진료과] — 야간·토요일 진료, 예약 문의" · "[증상] 상담 필요하세요? 진료시간·위치 확인 후 방문"
- KPI(범위): CTR 1%대 내외(정보 소구형이라 낮을 수 있으나 방문 질 높음), 예약·문의당 수천~수만원(진료과 편차), 재진 LTV 포함 판단

**⑤ 최적화 순서** **정책·소재 컴플라이언스(성과보다 우선)** → 랜딩(진료시간·예약·오시는길·주차) → 타겟(진료과별) → 예산(진료 가능 시간대)

## 6) 생활서비스 (인테리어·이사·청소·수리)

**① 왜 당근** — "급하게 근처 업체" 즉시성 수요 + 동네 평판이 결정적. 견적 문의가 채팅으로 바로 발생.

**② 비즈프로필 세팅**
- 카테고리: 인테리어/리모델링, 이사/용달, 청소(입주/이사), 설비·수리(누수·전기·보일러), 방역 등
- 대표키워드: `[○○동] 입주청소`, `원룸이사`, `화장실 리모델링`, `누수탐지`, `에어컨 청소`, `당일 수리`
- 사진: 대표=시공 결과 베스트컷(before/after 동일 조건·과장 금지) 또는 현장 / 시공 사례 포트폴리오·작업과정·장비·기사 소개·사업자·보험 등 신뢰요소(**펌사진·도용 금지, 우리 팀 실제 작업**)
- 소개글 필수: 서비스 범위, 견적 방법(무료 방문/사진 견적), 작업 가능 지역·시간, 사업자·보험·A/S, 경력·자격, 추가금 발생 기준 사전 고지(분쟁 예방)

**③ 소식·쿠폰·단골**
- 소식: 최근 시공 사례, 시즌 수요(장마 전 방수·겨울 보일러·이사철 청소), 셀프 관리 팁, 예약 가능 일정·긴급출동, 견적·비용 기준 설명
- 첫방문 쿠폰: "문의 시 방문 견적 무료" / "첫 이용 O만원 할인" / "에어컨 2대 이상 시 1만원 할인"
- 단골 락인: A/S 기간 연장, 정기 관리 계약 할인, 지인 소개 양쪽 할인, 시즌 재구매 리마인더

**④ 광고 캠페인**
- 목표: **견적·상담 문의**(사실상 유일 핵심 전환). 문의 즉응이 계약률 좌우
- 타겟: 서비스 권역 넓게 반경 5~10km 이상(청소·수리는 근거리, 이사·인테리어는 광역), 30~60대, 이사철(봄·가을)·연말 가중
- 예산: **월 30~100만원**(건당 단가 높아 문의당 여유 큼, 권역 넓어 도달에 예산 필요, 소규모 수리 하단/인테리어·이사 상단)
- 소재: 실제 시공 before/after·무료견적·당일방문 즉시성+후기·A/S("최저가·무조건" 등 최상급·보장 금지) / 카피 예) "○○동 입주청소 무료 견적 — 사진만 보내주시면 바로 안내" · "이사·수리 급하세요? 채팅 주시면 당일 방문 견적"
- KPI(범위): CTR 1~2%대, 견적문의당 수천~수만원(단가 커서 여유), 문의→계약 전환율(응대·견적 경쟁력)이 실질 ROI

**⑤ 최적화 순서** **응대·전환동선(채팅·전화 즉시 응답=계약률 최우선)** → 소재(실제 작업·무료견적) → 타겟(권역 반경·시즌) → 예산(이사철 집중)
