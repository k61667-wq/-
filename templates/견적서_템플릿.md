# 숨고 견적서 템플릿

> 아래 `{{ }}` 자리표시자는 자동화가 채웁니다. 숨고 메시지 글자수·톤에 맞게 다듬어 사용하세요.
> 숨고는 첫 메시지가 선착순으로 노출되므로, **핵심 3줄 + 견적표 + CTA** 구조가 반응률이 가장 좋습니다.

---

## A. 숨고 채팅 첫 메시지용 (짧은 버전, 복붙용)

```
안녕하세요, {{의뢰인_호칭}}님! {{업체명_또는_업종}} 관련 요청 확인했습니다.

요청 주신 "{{요청_핵심}}" 기준으로 아래와 같이 제안드립니다.

▪ 추천: {{상품명}} ({{채널}})
▪ 수량/기간: {{수량}}{{단위}} · {{기간}}
▪ 견적: {{합계금액}}원 (부가세 {{부가세포함여부}})

{{한줄_기대효과}}
비슷한 업종 진행 사례와 상세 플랜 바로 보내드릴 수 있습니다. 편하게 문의 주세요 :)
```

## B. 상세 견적서 (요청 시/2차 발송용)

```
■ {{업체명}} 마케팅 견적서
─────────────────────────
· 작성일: {{작성일}}
· 담당: {{담당자명}} / {{연락처}}

[요청 내용 요약]
{{요청_요약}}

[제안 견적]
┌─────────────┬──────┬──────┬───────────┐
│ 상품          │ 수량  │ 기간  │ 금액        │
├─────────────┼──────┼──────┼───────────┤
{{#each 항목}}
│ {{상품명}}    │ {{수량}} │ {{기간}} │ {{금액}}원 │
{{/each}}
├─────────────┴──────┴──────┼───────────┤
│ 공급가액                     │ {{공급가}}원 │
│ 부가세(10%)                  │ {{부가세}}원 │
│ 합계                         │ {{합계}}원   │
└────────────────────────────┴───────────┘

[기대 효과]
{{기대효과_2~3줄}}

[진행 방식]
1. 계약/입금 확인 → 2. {{리드타임}} 내 세팅 → 3. 진행현황 실시간 공유 → 4. 완료 리포트

[안내]
· 상기 금액은 {{유효기간}}까지 유효합니다.
· 키워드/URL/업종에 따라 단가가 조정될 수 있습니다.
```

---

### 톤 가이드
- 과장·보장성 표현("무조건 1위", "100% 보장") 금지 — 숨고 정책·신뢰도 문제.
- 숫자와 근거 위주. "실제 방문형 트래픽", "실방문 영수증" 등 차별점을 짧게.
- 첫 메시지는 200~300자 이내로. 길면 선착순 경쟁에서 안 읽힘.
