# 숨고 견적 자동응답 자동화

숨고에서 새 견적 요청(요청서)이 오면 **① 내용 확인 → ② 견적 기준표에서 매칭 → ③ 견적서 초안 자동 작성 → ④ 검토 후 전송**까지 이어지는 인바운드 영업 자동화입니다. (플레이스/블로그 트래픽·리뷰 마케팅 실행사용)

## 왜 "검토 후 전송"인가
숨고는 고수용 공개 API가 없어, 봇이 요청서를 읽고 앱에 자동 전송하는 완전 무인화는
약관 위반·계정정지 위험이 큽니다. 그래서 **초안 작성까지는 100% 자동**, **최종 전송만 사람이 30초**로 설계했습니다.
초안이 미리 준비돼 있어 선착순 경쟁 속도는 그대로 확보됩니다.
