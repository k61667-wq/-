# 광고대행 운영 자동화

당근 뉴스포스트 운영과 숨고 견적 응대, 두 가지 반복업무를 자동화한 설계·템플릿·스크립트 모음입니다.
공통 원칙은 하나입니다. **사람은 판단만 하고, 입력·복사·집계·보고는 기계가 합니다.**

---

## 프로젝트 1. 당근 뉴스포스트 운영 자동화

업체 등록 한 번으로 필수기재·키워드·콘셉트·초안·검수·진행률·중간보고까지 이어지는 운영 파이프라인입니다.

```
업체 등록(company_id 발번) → 정보 자동 저장 → 계정·프로필 연결 → 필수기재 자동 호출
→ 콘셉트 자동 생성 → 제목·본문 초안 자동 생성 → ★사람 검수★ → ★등록(붙여넣기)★
→ URL 저장 → 진행률 자동 갱신 → 중간보고 자동 생성
```

사람이 하는 일은 **★ 2곳**뿐입니다. 나머지는 자동입니다.

| 파일 | 내용 |
|---|---|
| `docs/뉴스포스트_운영자동화_설계서.md` | **여기부터 읽으세요.** 업무 분류(A/B/C/D) · 데이터 설계 · 단계별 자동화 · 절감 효과 계산 |
| `docs/뉴스포스트_구축가이드.md` | 시트 생성 → 스크립트 설치 → 운영 SOP |
| `templates/뉴스포스트_시트구조.md` | 7개 탭 전체 열 정의서 (입력/자동 구분) |
| `templates/중간보고_템플릿.md` | 중간보고 자동 생성 템플릿 |
| `prompts/콘셉트풀_생성_프롬프트.md` | 온보딩 시 업체당 콘셉트 20개 생성 |
| `prompts/뉴스포스트_초안_생성_프롬프트.md` | 제목 3안 · 본문 · 사진가이드 생성 |
| `prompts/뉴스포스트_자동검수_프롬프트.md` | 기계검수 규칙 + AI 2차 검수 |
| `scripts/뉴스포스트_자동화.gs` | Apps Script 전체 코드 (채번·자동호출·검수·알림·보고) |
| `data/뉴스포스트_*_seed.csv` | 각 탭 헤더 + 예시 행 |

### 핵심 설계 판단 3가지

1. **`company_id`로 연결한다** — 회사명 문자열로 연결하면 상호 변경·지점 확장·동명 업체에서 조용히 깨집니다.
2. **파생 데이터는 입력하지 않는다** — 진행률, 콘셉트 사용여부, 계정 최근사용일은 전부 수식입니다. 손으로 넣으면 반드시 틀어집니다.
3. **검수와 등록은 자동화하지 않는다** — 사실 확인은 법적 책임의 마지막 방어선이고, 당근 봇 게시는 계정 정지 위험입니다.

### 예상 효과 (업체 20곳 × 월 8건 = 160건 가정)

| | 현재 | 자동화 후 |
|---|---|---|
| 건당 소요 | 72분 | 18분 |
| 월 총 소요 | 약 211시간 | 약 53시간 |
| 절감 | — | **월 158시간 (75%)** |
| 도구 비용 | — | 월 약 4~6만원 |

가정값은 설계서 13장에서 실제 숫자로 교체해 재계산하세요.

### 시작하려면

1. 관리 업체 수 / 업체당 월 발행 목표 / 현재 실제 소요시간을 확인
2. 흩어져 있는 업체 정보 원본 시트 목록 확보
3. `docs/뉴스포스트_구축가이드.md` Phase 1(시트 만들기)부터 진행 — 이것만으로 절감 40%

## 프로젝트 2. 숨고 견적 자동응답

숨고에서 새 견적 요청이 오면 **① 내용 확인 → ② 견적 기준표 매칭 → ③ 견적서 초안 자동 작성 → ④ 검토 후 전송**까지 이어지는 인바운드 영업 자동화입니다.

숨고는 고수용 공개 API가 없어 봇 자동 전송은 약관 위반·계정정지 위험이 큽니다.
그래서 **초안까지는 100% 자동, 최종 전송만 사람이 30초**로 설계했습니다.

| 파일 | 내용 |
|---|---|
| `docs/자동화_구축가이드.md` | 전체 그림 · 준비물 · Make 구축 · 운영 SOP |
| `data/견적기준표_seed.csv` | 견적 기준표 시드 데이터 |
| `templates/견적서_템플릿.md` | 숨고 채팅용 짧은 견적 + 상세 견적서 |
| `prompts/견적_생성_프롬프트.md` | 의뢰서 파싱→매칭→초안 생성 프롬프트 + 출력 JSON 스키마 |

### 남은 할 일

1. 견적 기준표의 `판매단가` 예시값을 실제 판매가로 교체
2. 숨고 앱에서 새 요청서 이메일 알림 ON

---

## 두 프로젝트의 공통 원칙

- **자동화하지 않는 구간을 먼저 정한다** — 플랫폼 약관을 위반하는 자동 전송·자동 게시는 하지 않습니다. 사람이 마지막 30초를 씁니다.
- **AI는 사실을 만들지 않는다** — 프롬프트에 "제공 정보 밖의 사실 창작 금지"를 하드코딩하고, 모르는 값은 `[확인필요]` 토큰으로 남깁니다.
- **인증정보는 시트에 두지 않는다** — 비밀번호·복구코드는 볼트에, 시트에는 항목명만 적습니다.
