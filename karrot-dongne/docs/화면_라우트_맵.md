# Karrot Management 화면 라우트 맵

14분 33초 분량의 실제 작업 화면 녹화를 프레임 단위로 분석해 복원한 화면 구조입니다.
`inspect_selectors.py` 실행 결과가 나오면 여기에 실제 selector를 채워 넣습니다.

- 기준 호스트: `http://49.247.202.25:8080`
- 공통 상단바: `사용자명 · 업체목록 · 전체 아이디 · 하트/찜 · 로그아웃`
- 공통 푸터: `2026 cocolab`

## 라우트

| 경로 | 화면 | 파라미터 |
|---|---|---|
| `/karrotFront/login` | 로그인 | — |
| `/karrotFront/companies` | 업체 목록 | — |
| `/karrotFront/index` | 업체 상세 · 계정(토큰) 목록 | `businessId`, `usageType=post` |
| `/karrotFront/write` | 게시글 작성 | `tokenId`, `businessId` |
| `/karrotFront/posts` | 내 게시글 목록 | `tokenId`, `nickname`, `tokenType=post`, `businessId` |
| `/karrotFront/post` | 게시글 상세 · 댓글 · 대댓글 | `id`(게시글ID), `tokenId`, `businessId` |
| `/karrotFront/reviews` | 후기 관리 (비즈프로필) | `tokenId`, `nickname`, `businessId` |

> **중요:** 게시글 상세는 URL로 직접 접근해도 정상 동작합니다.
> 기존 SRS의 "홈 → 업체 검색 → 업체 진입 → 게시물 찾기" 재진입 우회 절차(FR-009)는 필요 없습니다.

## 코스트(크레딧) 과금

헤더에 `내 코스트 NNN` 이 표시되며 행동마다 차감됩니다.

| 행동 | 차감 |
|---|---|
| 토큰(계정) 생성 | −1 |
| 계정 조회 | −1 |

영상 14분 동안 `232 → 200` (32 소진). 자동화는 사람보다 빠르므로 **예산 가드가 필수**입니다.
매 작업 전 잔액을 읽고, 임계치 이하이거나 작업 예상 소모량보다 적으면 시작하지 않습니다.

## 화면별 구성

### 로그인 `/login`
아이디 input · 비밀번호 input · `[로그인]` · `[회원가입]`
성공 판정: 상단바에 사용자명이 나타남.

### 업체 목록 `/companies`
- 검색창 `업체명 또는 주소로 검색`
- `내 코스트` 뱃지 · **`[일괄 토큰 배정]`** 버튼 ← 기능 확인 필요
- 표: 체크박스 · 번호 · 업체명 · 주소 · 비즈 프로필 링크 · 메모 · 등록일 · 관리 `[동네생활][비즈프로필]`
- 페이지네이션 (관측 시점 `1/31`)
- 우하단 주황 FAB `+` → **업체 추가 모달**: `업체명*` · `업체 주소` · `비즈 프로필 링크` · `메모` / `[취소][추가]`
- 추가 성공 시 `alert("업체가 추가되었습니다.")`

### 업체 상세 `/index?businessId=&usageType=post`
- 업체명 + `내 코스트` + `[수정]`, 주소, 비즈프로필 링크
- 검색창 `주소 또는 닉네임으로 검색`
- `지역으로 이동 (예: 군포시, 대야미동)` + `[지역 이동]`
- 탭: `[동네생활 작업]`(주황) / `[비즈프로필 작업]`(보라) — 같은 계정 목록, 액션 의미가 다름
- 계정 표 컬럼:
  `번호 | 주소 | 닉네임 | 온도 | 인증 | 후기/동네 | 작업일 | 작업내용 | 가입일 | 메모 | 조회 | 프로필 | 링크 | 관리`
  - 작업일 `[날짜선택]` 또는 날짜 뱃지
  - 작업내용 `[내용]` / `[사용불가]`(주황) / 임의 텍스트 뱃지
  - 메모 `[메모]` / `[사용금지]` / `[후기 많이사용]`
  - 조회 `[조회][선택]` · 프로필 `[사진]` · 링크 `[당근][복사]` 또는 `-`
  - 관리 `[폐기][주소변경]`
- 행 색상: 흰색 = 미작업 / 초록 = 오늘 작업 완료 / 분홍 테두리 = 과거 작업 이력
- 우하단 FAB 2개: 파랑 돋보기(검색), 주황 `+`(토큰 추가)

#### 토큰 추가 모달
탭 `[동네생활][비즈프로필]` · 입력1 `주소 검색` · 입력2 `상세주소를 입력하세요` · `[제출]` · `[닫기]`
성공 시 `alert("토큰이 추가되었습니다. (ID: 228031)")` → **확인 후 페이지 전체 리로드**
→ alert 문자열에서 토큰 ID를 정규식으로 추출해 시트에 저장할 것.

#### 주소(동네) 변경 모달
- 제목 `주소(동네) 변경`, `현재 주소: {동}`
- 입력 `변경할 동네 검색 (예: 남가좌동)` → **타이핑 시 자동완성 드롭다운**
- 항목 클릭 → `선택한 동네: 경기도 수원시 영통구 망포동` 표시
- `[변경]` 은 선택 전 비활성 → 클릭 시 `변경 중...` → `alert("주소가 변경되었습니다.")`
- `[취소]`

> 후보가 정확히 1건이면 자동 선택, 2건 이상이면 사용자 선택 요청, 0건이면 `MANUAL_REQUIRED`.
> 선택 후 "선택한 동네" 값을 다시 읽어 목표 주소와 일치할 때만 `[변경]` 을 누른다.

### 게시글 작성 `/write?tokenId=&businessId=`
- `작성 계정` 카드 (닉네임 · 동 · 온도 · 인증 횟수) — 읽기 전용, `tokenId` 로 결정됨
- `주제 선택` `<select>` (관측된 값: `고민/사연`) ← **전체 옵션 목록 수집 필요**
- `제목` input `제목을 입력해주세요.`
- `내용` **textarea** `내용을 입력해주세요.` (리치 에디터 아님)
- `장소 추가` `[📍 장소 검색]`
- `이미지 첨부 0/10` `[사진 선택 (최대 10장)]`
- `[이미지 업로드]` `[등록하기]`
- 등록 후 `/posts?tokenId=...` 로 이동

### 내 게시글 목록 `/posts?tokenId=`
카드: `[게시됨]` 뱃지 · 날짜 · 제목 · 본문 요약
버튼: `[당근 바로가기]` `[링크 복사]` `[댓글]`

> 링크는 클립보드 대신 `[당근 바로가기]` 의 `href` 를 읽거나,
> 게시글 상세 URL의 `id` 값으로 조립하는 편이 안정적입니다.

### 게시글 상세 `/post?id=&tokenId=&businessId=`
- 게시글 카드: 작성자 닉네임/동/날짜 · `[수정][삭제]` · 제목 · 본문
  - `좋아요 현황 N` · 이모지 반응 4종 카운트
- `댓글 (N개)` + `[🔄 최신화]`
  - 빈 상태 `댓글이 없습니다.` / 로딩 `댓글을 불러오는 중...`
- 댓글 아이템: `닉네임 | 동 | MM-DD HH:mm | #86315617`
  - `[👍 N] [답글] [수정] [삭제]`
- **답글 인라인 폼**: `계정 선택 <select>` (게시글 작성자가 기본 선택됨) · textarea ·
  `[📍 장소 추가][🖼 이미지 첨부]` · `[취소][등록]`
- 하단 고정 댓글 입력바:
  `댓글 계정 선택 <select>` (옵션 포맷 `닉네임 | 동 | 36.5°C | 인증 1회 | -`) · 📍 · 🖼 ·
  `댓글을 입력해주세요.` · `[등록]`

> 댓글마다 `#86315617` 형태의 고유 ID가 화면에 노출됩니다.
> 새로고침 후 중복 등록 방지는 이 ID(또는 원고 텍스트) 존재 여부로 판정합니다.

### 후기 관리 `/reviews?tokenId=&nickname=&businessId=`
- `{닉네임} - 후기 관리`, 계정 / 토큰 ID 표시
- `비즈 프로필 검색`: input `업체명을 입력하세요...` + `[검색]`
  - 진행 `검색 중` / 실패 **`검색 결과가 없습니다.`** (실제 발생함)
  - 성공 시 결과 카드 → 클릭하면 `[선택됨]` 뱃지 + 업체명 + 업종, `[×]` 해제
- `후기 작성`: 별점 5개 · 내용 textarea · `[🖼 이미지 첨부]` · `[후기 등록]`
  - 안내 `* 비즈 프로필을 선택해야 등록 버튼이 활성화됩니다.`
- 하단 `후기 목록` 총 N건
- 등록 성공 시 폼 자동 초기화

## 실물에서 추가 확인이 필요한 것

1. `주제 선택` `<select>` 의 **전체 옵션 목록**
2. 업체 목록의 **`[일괄 토큰 배정]`** 이 하는 일 — 이미 일괄 기능이 있으면 토큰 생성 자동화가 불필요할 수 있음
3. `사용불가` 판정이 어느 시점에 갱신되는지 (조회 시점인지 별도 경로인지)
4. 토큰 추가 모달의 `주소 검색` 필드에도 자동완성 드롭다운이 있는지
5. 같은 계정 재사용 쿨다운에 대한 사내 운영 규칙
