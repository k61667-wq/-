# 동네생활 업무 자동화 (Karrot Management)

사내 관리 도구 **Karrot Management**(`49.247.202.25:8080`)에서 반복 수행하는
업체 등록 → 계정(토큰) 생성 → 주소 검증 → 동네생활 게시글·댓글·대댓글 → 후기 작성 →
작업 이력 기록까지를 자동화하는 프로젝트입니다.

## API 없이 만듭니다

이 시스템은 **공개 API가 없습니다.** 그래서 사람이 화면을 쓰는 방식 그대로,
브라우저를 프로그램이 조종하는 **UI 자동화(Playwright)** 로 만듭니다.
API가 없다고 해서 설계가 달라지지 않으며, 실제로 필요한 것은 API가 아니라
**각 화면의 버튼·입력창을 어떻게 찾을지에 대한 정보(selector)** 뿐입니다.

그 정보를 사람이 F12로 일일이 뜯을 필요 없이 자동으로 수집하는 것이
`inspect_selectors.py` 입니다.

## 지금 할 일 — 딱 한 번

회사에서 허용된 IP 환경의 PC에서:

```bash
pip install playwright
playwright install chromium
python inspect_selectors.py
```

브라우저 창이 뜨면 **직접 로그인**만 하시면 됩니다.
그 다음부터는 스크립트가 알아서 화면을 돌며 구조를 수집하고,
`karrot_dump/` 폴더를 만듭니다.

| 파일 | 내용 |
|---|---|
| `karrot_dump/report.json` | 화면별 버튼·입력창·표·드롭다운 구조 **(이 파일이 핵심)** |
| `karrot_dump/html/` | 화면별 원본 HTML |
| `karrot_dump/shot/` | 화면별 스크린샷 |

이 폴더를 공유해 주시면 실제 자동화 코드를 작성할 수 있습니다.

### 이 스크립트가 안전한 이유

계정 생성이나 조회는 **코스트(크레딧)를 차감**하므로, 수집기는 다음을 지킵니다.

- `제출 / 등록 / 추가 / 생성 / 변경 / 조회 / 삭제 / 폐기 / 확인` 이 들어간 버튼은 **누르지 않습니다**
- 브라우저 alert 이 뜨면 **무조건 취소**로 닫습니다
- 페이지 이동, DOM 읽기, 모달 **열기**만 합니다 — 어떤 데이터도 만들지 않습니다

즉, 실행해도 코스트가 줄지 않고 계정도 생기지 않습니다.

## 자동화 범위 (영상 분석 기준)

| | 단계 |
|---|---|
| 완전 자동화 | 로그인 · 업체 목록/추가/진입 · 토큰 생성 · 조회 · 게시글 작성 · 댓글 · 대댓글 · 작업 이력 기록 |
| 조건부 (사람 개입 지점 명시) | 주소(동네) 변경 — 후보 2건 이상이면 사용자 선택 / 게시글 링크 확보 / 후기 — 비즈프로필 검색 실패 시 중단 |
| 자동화 제외 | 카카오톡 전송 — 보고문 생성까지만 자동, 발송은 사람이 |

## 설계 원칙

1. 원고(제목·본문·댓글·후기)는 코드가 아니라 **Google 스프레드시트**에서 읽는다.
2. 모든 단계는 **결과를 검증한 뒤에만** 다음 단계로 넘어간다.
3. 화면 좌표 클릭은 쓰지 않는다. id → data 속성 → name → role+이름 → 텍스트 순으로 찾는다.
4. **코스트 잔액을 매 작업 전에 확인**하고, 임계치 이하면 시작하지 않는다.
5. IP 제한을 우회하는 기능은 만들지 않는다. 허용된 네트워크에서만 실행한다.
