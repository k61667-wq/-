# 숨고 견적 생성기 (tools/견적생성기.py)

의뢰서를 넣으면 → 견적 기준표에서 상품을 매칭하고 → **단가·부가세를 코드로 계산**해
→ 숨고 붙여넣기 문구 + 상세 견적서를 만들고 → `data/견적로그.csv`에 자동 기록합니다.

가이드 문서의 **방식 B(반자동)** 를 "한 줄 실행"으로 만든 도구입니다.
Python 3만 있으면 되고, **설치·Gmail/Make 인증이 필요 없습니다.**

## 바로 써보기

```bash
# 동봉된 샘플로 실행
python3 tools/견적생성기.py --의뢰서 data/샘플_의뢰서.txt --담당 "홍길동" --연락처 "010-1234-5678"
```

## 실제 사용 (요청서가 오면)

```bash
# 방법 1) 의뢰서를 파일로 저장 후
python3 tools/견적생성기.py --의뢰서 요청서.txt

# 방법 2) 그냥 붙여넣기 — 실행 후 의뢰서 붙여넣고 Ctrl+D
python3 tools/견적생성기.py
```

출력: **① 숨고 채팅 붙여넣기용 문구**, **② 상세 견적서**. 검토가 필요하면
상단에 `⚠ 검토필요`와 이유가 표시됩니다. 그대로 복사해 숨고에 붙여넣으면 끝.

## 왜 안전한가 (환각 가격 차단)
- 단가는 **오직 `data/견적기준표_seed.csv`에서만** 읽습니다. AI가 가격을 지어낼 수 없습니다.
- 부가세(10%)·합계는 코드가 계산합니다.
- 매칭 키워드가 없거나 / 후보가 동점이거나 / 단가 미입력 / 예산 초과이면 **자동으로 검토필요** 처리.

## 옵션
| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--의뢰서 PATH` | 의뢰서 텍스트 파일 (없으면 표준입력) | – |
| `--기준표 PATH` | 견적 기준표 CSV | `data/견적기준표_seed.csv` |
| `--로그 PATH` | 견적로그 CSV | `data/견적로그.csv` |
| `--담당 이름` / `--연락처 번호` | 상세 견적서에 표기 | 빈칸 |
| `--json` | 자동화 연동용 JSON 도 출력 | off |
| `--no-log` | 로그 기록 생략 | off |

## 품질개선 루프 (월 1회)
`data/견적로그.csv`의 **`성사여부(수기)`** 칸에 성사되면 `Y`, 안 되면 `N`을 채워두세요.
쌓이면 어떤 상품·단가가 잘 성사되는지 보이고, 기준표의 `매칭키워드`·`판매단가`를
조정하는 근거가 됩니다(가이드 5장).
