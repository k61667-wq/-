교차 출처(iframe) 경계 테스트

대상 사이트를 iframe에 로드한 뒤, 부모 문서에서 DOM 접근을 시도합니다. 정상적인 브라우저에서는 반드시 차단되어야 하며, X-Frame-Options / CSP frame-ancestors 가 설정된 사이트는 로드 자체가 거부됩니다. 이 결과가 "가능한 것 / 불가능한 것"의 실제 경계입니다.

(iframe 미로드)

대상 페이지에서 직접 실행하기

1) 대상 페이지를 열고 DevTools(F12) → Console. 2) tools/browser_capability_probe.js 전체를 붙여넣고 Enter. 3) copy(JSON.stringify(window.__BROWSER_PROBE_RESULT__)) 로 결과 복사. 헤더 기반 CSP·HttpOnly 쿠키·서버 헤더는 tools/run_probe.mjs(Playwright)로만 확인됩니다.

(아직 실행 전)
