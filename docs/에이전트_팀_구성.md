# 에이전트 팀 구성 (Agent View 운영 가이드)

이 저장소에는 마케팅 대행 + 숨고 견적 자동화 업무를 나눠 맡는 **서브에이전트 15종**이
`.claude/agents/`에 정의되어 있습니다. `claude agents`(에이전트 뷰)에서 병렬로 굴리거나,
세션 안에서 `@이름`으로 호출할 수 있습니다.

## 빠른 사용법
```bash
cd <이 저장소>
claude agents                                  # 에이전트 뷰(대시보드) 진입

# 백그라운드로 특정 에이전트 실행 (병렬 가능)
claude --agent naver-seo   --bg "○○동 헬스장 키워드 20개 + 우선순위표"
claude --agent danggeun-ads --bg "예산 30만원 캠페인 설계 + 소재 A/B 2안"

# 세션 안에서 호출
@sales 이 의뢰서 견적 초안 다듬어줘
```
뷰 조작: `↑↓` 이동 · `Space` 미리보기 · `Enter/→` 붙기 · `←` 복귀 · `Ctrl+S` 그룹전환 · `?` 단축키

## 팀 구성 (채널·기능별)

### 🛠 자동화 · 개발
| 에이전트 | 역할 |
|---|---|
| `coder` | 코드 작성·수정·리팩터링, 파서·데이터 처리, JSON 스키마 구현 |
| `workflow-builder` | Make 자동화 시나리오 설계(Gmail→파싱→견적초안→검토전송) |
| `test-runner` | 견적 파이프라인 QA·회귀 검증(검증 전용, 수정 안 함) |
| `doc-writer` | 구축·운영 가이드·SOP·템플릿·README 문서화 |

### 🥕 당근(당근마켓)
| 에이전트 | 역할 |
|---|---|
| `danggeun-profile` | 비즈프로필 세팅·운영(사진·소개글·소식·쿠폰·후기) = 랜딩/전환 |
| `danggeun-ads` | 당근 광고 퍼포먼스(캠페인·소재 A/B·CPC·CPA 최적화) = 유입/성과 |

### 🟩 네이버
| 에이전트 | 역할 |
|---|---|
| `naver-seo` | 키워드 추출·상위노출·플레이스 프로필·리워드/트래픽 순위작업 |
| `naver-content` | 블로그 발행 + 숏폼 제작 |
| `naver-cafe` | 카페 생성 + 커뮤니티 글 작성·운영 |
| `naver-web` | 홈페이지/랜딩 제작(전환 최적화) |

### 🎯 공통 마케팅 · 디자인
| 에이전트 | 역할 |
|---|---|
| `marketer` | 플레이스/블로그 트래픽·리뷰 마케팅 기획·카피·SEO·프로모션 |
| `designer` | 견적서·상세페이지·SNS 카드·슬라이드·목업(Figma/Canva/Gamma) |

### 🏢 경영지원
| 에이전트 | 역할 |
|---|---|
| `operations` | 운영 SOP·일정·업무 조율·프로세스 개선(Notion/Calendar/Drive) |
| `accountant` | 회계·정산·단가/마진 계산·수익성 검토 |
| `sales` | 숨고 견적 초안 검토·고객 응대·팔로업(최종 전송은 사람) |

## 협업 흐름 (퍼널)

```
[유입]                    [랜딩/전환]                 [운영]
naver-seo ─┐
naver-content ─┼─▶ naver-web / danggeun-profile ─▶ sales ─▶ accountant
danggeun-ads ─┘                                         operations (전 과정 조율)
naver-cafe ─┘
```

- 광고·검색 담당(`*-ads`, `naver-seo`)은 성과가 낮을 때 **소재/타겟 문제인지 vs 랜딩/전환 문제인지** 구분하고,
  후자면 `naver-web`·`danggeun-profile`와 협업한다.
- 코드·자동화 이슈는 `coder`·`workflow-builder`, 품질 검증은 `test-runner`.

## 공통 원칙 (전 에이전트)
1. **정책·법 준수**: 플랫폼 약관, 표시광고법(대가성 후기/광고 표기)을 지키고 리스크는 고지한다.
2. **근거 있는 카피**: 구체적 수치·혜택 중심. "1위 보장" 등 근거 없는 약속 금지.
3. **판매 가능한 제안만**: 단가·상품은 `data/견적기준표_seed.csv` 기준.
4. **숨고 핵심 제약**: 견적은 **초안까지만 자동, 최종 전송은 사람**(약관·계정정지 리스크).

## 에이전트 추가·수정
정의 파일은 `.claude/agents/<이름>.md`. frontmatter(name/description/tools/model/color/mcpServers)만
고치면 역할·권한·모델을 바꿀 수 있다. 새 채널(인스타·유튜브 등) 담당도 같은 형식으로 추가한다.
