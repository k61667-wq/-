# 숨고 견적 자동응답 — 구축 & 운영 가이드

## 0. 전체 그림 (한눈에)

```
[숨고 새 요청서]
      │  (숨고가 보내는 '요청서 도착' 이메일)
      ▼
① Gmail 트리거  ──→ ② 의뢰서 파싱(AI) ──→ ③ 견적 기준표 조회(Google Sheets)
                                                     │
                                                     ▼
                                      ④ 견적서 초안 생성(AI + 템플릿)
                                                     │
                                                     ▼
          ⑤ 나에게 검토 요청(카톡/슬랙/이메일로 초안 + '전송문구' 전달)
                                                     │
                                        (내가 확인 → 복사)
                                                     ▼
          ⑥ 숨고 앱/웹에 붙여넣기 → 전송  ← 사람이 하는 유일한 단계
```

**핵심 원칙:** ①~⑤는 완전 자동, ⑥만 사람이 30초. 숨고 공개 API가 없어서 ⑥ 자동화는
계정정지·약관위반 위험이 크므로 의도적으로 사람이 최종 전송합니다(선착순 속도는 초안이 미리 준비돼 충분).

---

## 1. 준비물 체크리스트

| 항목 | 상태 | 비고 |
|---|---|---|
| 견적 기준표 (Google Sheets) | ✅ 생성됨 | "숨고 견적 기준표 (자동화용)" — **판매단가를 실제 값으로 교체 필요** |
| 견적서 템플릿 | ✅ `templates/견적서_템플릿.md` | |
| 매칭 프롬프트 | ✅ `prompts/견적_생성_프롬프트.md` | |
| Gmail 연결(인증) | ⛔ **인증 필요** | claude.ai 커넥터 설정에서 Gmail authorize |
| 자동화 엔진(Make) | ⬜ 선택 | 아래 2가지 방식 중 택1 |
| 숨고 이메일 알림 ON | ⬜ 확인 필요 | 숨고 앱 → 알림 설정에서 이메일 알림 켜기 |

---

## 2. 가장 먼저 할 일 (사장님 액션 2가지)

1. **견적 기준표 판매가 교체**
   시트 링크를 열어 `판매단가_부가세별도` 열의 예시값(70/80/…)을 실제 판매 단가로 바꿉니다.
   `참고원가_내부` 열은 내부 원가(숨고 노출 X)이니 참고용으로만 두세요.

2. **숨고 이메일 알림 켜기**
   숨고 앱 → 설정 → 알림 → '새 요청서' 이메일 수신을 ON.
   (이 이메일이 자동화의 방아쇠입니다. 안 오면 트리거가 작동하지 않습니다.)

---

## 3. 구현 방식 — 2가지 중 선택

### 방식 A. Make(노코드) 상시 자동화 — **비개발자 추천**

24시간 서버가 Gmail을 감시하다가 자동 실행. 사장님이 자리에 없어도 초안이 미리 준비됨.

**시나리오 모듈 구성:**

1. **Gmail › Watch Emails**
   - 필터: `from:no-reply@soomgo.com` (또는 숨고 발신주소) `subject:요청서`
   - 신규 메일 1건 = 트리거 1회

2. **Text parser / Set variable**
   - 메일 본문에서 의뢰 내용 텍스트 추출

3. **Google Sheets › Search Rows**
   - 스프레드시트: "숨고 견적 기준표 (자동화용)"
   - 전체 행을 읽어 다음 AI 모듈에 전달

4. **OpenAI/Anthropic › Create Completion (AI 모듈)**
   - System: `prompts/견적_생성_프롬프트.md`의 System Prompt 붙여넣기
   - User: 의뢰서 원문 + 시트 CSV (2번·3번 결과 매핑)
   - 출력: JSON

5. **분기(Router)**
   - `needs_review = true` → 6번으로 (사람 확인 강조 라벨)
   - `false` → 그대로 6번

6. **알림 발송 (택1)**
   - **Kakao/Slack/Telegram › Send Message** 또는 **Gmail › Send Email(본인에게)**
   - 내용: `chat_message`(숨고 붙여넣기용) + 견적표 + assumptions + needs_review 표시

7. (선택) **Google Sheets › Add Row** — '견적로그' 탭에 발송 이력 기록

> Make 시나리오는 MCP로 자동 생성도 가능합니다. 진행하려면 Make의
> **Organization ID / Team ID**를 알려주시면 골격을 만들어 드립니다.

### 방식 B. Claude(대화형) 반자동 — 지금 바로 가능

상시 감시는 아니지만, 요청이 오면 사장님이 이 세션(또는 Claude)에 의뢰서를 붙여넣고
"견적 뽑아줘"라고 하면 즉시 초안을 만들어 드립니다. Gmail 인증 없이도 동작.

- 절차: 의뢰서 복붙 → Claude가 시트 조회 → 견적서 초안 + 숨고 붙여넣기 문구 출력 → 검토 후 전송
- 장점: 오늘 바로 사용, 애매한 건은 대화로 즉시 보정
- 단점: 사장님이 트리거(붙여넣기)를 직접 해야 함

**추천 로드맵:** 오늘은 방식 B로 바로 쓰고, Gmail 인증 후 방식 A로 상시화.

---

## 4. 운영 SOP (매일)

1. 알림(카톡/메일) 도착 → 초안·`chat_message` 확인
2. `needs_review=true`거나 금액이 큰 건이면 5초 검토·수정
3. 숨고 앱에서 해당 요청 열기 → 문구 붙여넣기 → 전송
4. (선택) 견적로그 시트에 성사 여부 체크 → 매칭 품질 개선에 활용

## 5. 품질 개선 루프

- 안 팔린 견적/성사된 견적을 로그에 남기고, 월 1회 `매칭키워드`·`판매단가`를 조정합니다.
- 자주 오는 의뢰 유형이 기준표에 없으면 **행을 추가**하면 다음부터 자동 매칭됩니다.

## 6. 리스크 & 주의

- 숨고 계정 자동 로그인/자동 전송 봇은 **약관 위반·정지 위험** → 하지 않습니다(⑥은 사람).
- AI가 지어낸 가격 방지: 프롬프트 규칙 1번(기준표 외 가격 금지)을 유지하세요.
- 개인정보: 의뢰서에 연락처가 포함될 수 있으니 로그 시트 공유 범위를 최소화하세요.
