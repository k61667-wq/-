# 변수 매핑표 & Docs 템플릿 배치 가이드

Google Docs 계약서 템플릿에 아래 `{{변수}}` 를 **그대로 타이핑**해 두면,
계약서 생성 시 실제 값으로 치환됩니다. (정의: `apps-script/VariableMapping.gs`)

## 전체 변수 목록

|---|---|
| `{{계약번호}}` | CW-20260725-0001 |

### Ⅱ. 용역의 내용 및 대가 — 표 8행
표를 8행으로 만들고 각 행의 셀에 아래를 배치(N = 1~8):

| 열 | 변수 | 비고 |
|---|---|---|
| 용역 항목 | `{{항목N_명}}` | 예: 비즈프로필 후기 |
| 수량·기준 | `{{항목N_수량}}` | 예: `20 건` (미포함이면 `-`) |
| 단가 | `{{항목N_단가}}` | 콤마 숫자, 예: `15,000` |
| 금액 | `{{항목N_금액}}` | 콤마 숫자, 예: `300,000` |

> 세부 내용(설명) 열은 패키지와 무관하게 고정이므로 템플릿에 **평문으로** 그대로 적어두면 됩니다.

## 팁
- 변수는 반드시 **중괄호 2개** `{{ }}` 로 감싸고, 오타(띄어쓰기 포함) 없이 표와 동일하게.
- 서명란의 갑 상호/대표자/소재지에도 `{{갑_상호}}` 등을 재사용하면 한 번에 채워집니다.
- 사용하지 않는 변수는 빈 값("")으로 치환되어 문서에 남지 않습니다.
