# 변수 매핑표 & Docs 템플릿 배치 가이드

Google Docs 계약서 템플릿에 아래 `{{변수}}` 를 **그대로 타이핑**해 두면,
계약서 생성 시 실제 값으로 치환됩니다. (정의: `apps-script/VariableMapping.gs`)

## 전체 변수 목록

### Ⅱ. 용역의 내용 및 대가 — 표 (최대 6행)
표를 **6행**으로 만들고 각 행의 셀에 아래를 배치(N = 1~6).
패키지 항목이 5개면 6번째 행은 자동 삭제되고, 6개면 그대로 채워집니다.

| 열 | 변수 | 비고 |
|---|---|---|
| 용역 항목 | `{{항목N_명}}` | 예: 비즈프로필 후기 |
| 세부 내용 | `{{항목N_세부}}` | 예: 좋은 후기로 고객 신뢰도 상승 |
| 수량(개) | `{{항목N_수량}}` | 예: `5` |
| 단가(원) | `{{항목N_단가}}` | 콤마 숫자, 예: `5,000` |
| 금액(원) | `{{항목N_금액}}` | 콤마 숫자, 예: `25,000` |

> ※ '개월 수' 열은 표기하지 않습니다(계약기간에만 표시).

> 세부 내용도 패키지마다 문구가 달라 변수(`{{항목N_세부}}`)로 처리합니다.
> ⚠️ 반드시 표의 **1열이 `No`, 2열이 `{{항목N_명}}`** 이어야 빈 행 자동삭제가 정확히 동작합니다.

### Ⅱ. 금액 요약 — 부가세 표기 토글 지원
| 변수 | 예시 값 |
|---|---|
| `{{패키지명}}` | 동네확보 프로젝트 |
| `{{총공급가액}}` | ￦320,000 |
| `{{패키지할인}}` | − ￦70,000 |
| `{{부가세}}` | ￦25,000 |
| `{{총계약금액}}` | ￦275,000 |
| `{{계약금액라벨}}` | `(VAT 포함)` 또는 빈칸 |

**부가세 포함/별도 선택** (`vatMode`):
- **VAT 포함**(기본): 총계약금액 옆에 `{{계약금액라벨}}` = `(VAT 포함)` 표시, 부가세 줄 생략.
- **VAT 별도**: `{{계약금액라벨}}` = 빈칸. 요약에 `{{부가세}}` 줄을 추가로 배치하면 부가세가 별도 줄로 표기됩니다.

> 4개 패키지: **동네확보(275,000) · 동네선점(825,000) · 동네점유(1,650,000) · 동네장악(3,300,000)** (모두 VAT 포함 기준)

## 팁
- 변수는 반드시 **중괄호 2개** `{{ }}` 로 감싸고, 오타(띄어쓰기 포함) 없이 표와 동일하게.
- 서명란의 갑 상호/대표자/소재지에도 `{{갑_상호}}` 등을 재사용하면 한 번에 채워집니다.
- 사용하지 않는 변수는 빈 값("")으로 치환되어 문서에 남지 않습니다.
