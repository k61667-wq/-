# 배포 가이드 (한 번만 세팅, 30분)

개발 지식 없이도 따라할 수 있도록 순서대로 정리했습니다.

---

## STEP 0. 준비물
- 회사 Google 계정 (Sheets·Docs·Drive·Gmail 사용)
- 이 저장소의 `apps-script/` 코드와 `data/` CSV

---

## STEP 1. 데이터베이스 스프레드시트 만들기
1. Google Sheets 에서 새 문서 생성 → 이름 예: **`커넥트와이즈 계약 DB`**
2. 상단 메뉴 **확장 프로그램 → Apps Script** 클릭 → 편집기 열림
3. 편집기에서 `apps-script/` 의 **9개 파일을 그대로 생성**해 붙여넣기
   - `.gs` 8개(Config·Database·Calc·Dates·VariableMapping·ContractGenerator·Code·Renewals·Setup)
   - `Sidebar.html` 1개 (파일 추가 → HTML)
   - `appsscript.json` 은 편집기 ⚙️설정에서 "매니페스트 표시" 후 내용 교체
4. 저장(💾) → 시트로 돌아가 **새로고침**
5. 시트 메뉴에 **`📄 계약서 자동생성`** 이 보이면 → **초기 설정 → (Apps Script에서 `initSheets` 1회 실행)**
   - 편집기에서 함수 `initSheets` 선택 후 ▶실행 → 권한 승인 → 5개 탭 자동 생성

## STEP 2. 시드 데이터 넣기
1. `data/SalesReps.csv` 내용을 `SalesReps` 탭에 붙여넣기 (헤더 아래부터)
2. 같은 방식으로 `Packages` / `PackageItems` / `Customers` 붙여넣기
3. **⚠️ 예시 숫자를 실제 값으로 교체** — 담당자 연락처, 4개 패키지의 수량·단가·할인
   - `PackageItems` 의 `qty`·`unit_price` 만 정확히 넣으면 `amount`·공급가액·계약금액은 자동 계산됩니다
   - `Packages` 의 `net_supply/vat/contract_total` 은 비워두면 자동, 특정 라운딩을 원하면 직접 입력

## STEP 3. Docs 계약서 템플릿 만들기
1. `prototype/contract-interactive.html` 를 브라우저로 열고 **인쇄 → PDF** 로 최종 디자인 확인
2. Google Docs 새 문서에 계약서 본문을 옮기고, 값이 들어갈 자리에 **변수**를 타이핑
   - 예: 담당자 칸에 `{{담당자_이름}}`, 금액 칸에 `{{총계약금액}}`
   - 용역표는 8행 표를 만들고 각 셀에 `{{항목1_수량}}` `{{항목1_단가}}` `{{항목1_금액}}` … 배치
   - 전체 변수 목록: `docs/03_변수매핑표.md`
3. 이 Docs 의 **문서 ID** 복사 (URL 의 `/d/`와 `/edit` 사이 문자열)

## STEP 4. 저장 폴더 만들기
1. Drive 에 폴더 생성 예: **`계약서 보관함`**
2. 폴더 **ID** 복사 (URL 의 `folders/` 뒤 문자열)

## STEP 5. Config 연결
Apps Script 편집기에서 `Config.gs` 를 열고 2줄 교체:
```js
TEMPLATE_DOC_ID: '3단계에서 복사한 Docs ID',
ROOT_FOLDER_ID:  '4단계에서 복사한 폴더 ID',
```
필요 시 `COMPANY.*`(을 정보)·`AUTO_EMAIL`·`RENEWAL_NOTICE_DAYS` 도 조정.

## STEP 6. 점검 & 첫 계약서
1. 시트 메뉴 `📄 계약서 자동생성 → 초기 설정 점검` → 모두 ✅ 인지 확인
2. `계약서 만들기` → 사이드바에서 고객·담당자·패키지·날짜 선택 → **계약서 생성**
3. 결과 링크(PDF·Docs·폴더) 확인. `Contracts` 탭에 로그가 남았는지 확인

## STEP 7. 갱신 알림 켜기 (선택)
Apps Script 편집기에서 `installTriggers` 1회 실행 → 매일 09:00 만료 임박 계약을 담당자에게 메일.

---

## 자주 묻는 점
- **완전 자동 발송 안 되나요?** 가능하지만(사이드바 체크박스) 계약서는 검토 1회를 권장합니다.
- **패키지를 5개로 늘리려면?** `Packages`·`PackageItems` 에 행만 추가하면 코드 수정 없이 드롭다운에 나옵니다.
- **단가만 바꾸려면?** `PackageItems` 의 `unit_price` 만 수정 → 다음 생성부터 자동 반영.
- **디자인을 못 살리겠어요.** Docs 대신 이 `prototype/contract-interactive.html` 를 그대로 써도 됩니다(브라우저에서 선택 → PDF 저장). Google 자동저장/이메일만 빠집니다.
