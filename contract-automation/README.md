# 커넥트와이즈 계약서 자동화 시스템

기존 계약서는 **수량·단가·금액·기간을 매번 손으로 입력·계산**해야 해서 느리고 실수가 잦았습니다.
이 시스템은 직원이 **고객 · 담당자 · 패키지 · 날짜 4가지만 선택**하면
나머지 값·계산·문서·PDF·Drive 저장까지 **자동**으로 처리합니다. → **계약서 1건 3분 이내.**

## 자동화되는 6가지 (요청 사항)
1. ✅ **영업 담당자 드롭다운** → 이름·연락처·이메일·부서 자동입력
2. ✅ **패키지 선택(4종)** → 8개 용역 항목의 수량·기준·단가·금액 자동채움
3. ✅ **총 공급가액 자동 계산** (Σ 금액)
4. ✅ **총 계약금액 자동 계산** (공급가액 − 패키지할인 + VAT, 즉시 갱신)
5. ✅ **계약기간 날짜 피커** → 시작일+개월수 → 종료일·기간 자동
6. ✅ **계약체결일 날짜 피커** → 문서 전체에 자동 반영

추가로: 고객 DB 자동입력 · 계약번호 자동생성 · 파일명/폴더 자동 · PDF 자동 · Drive 저장 · 이력 로그 · 만료 갱신 알림.

실제 계약서 디자인 그대로 자동 채워지고, **인쇄 → PDF 저장**까지 됩니다.
(회사 디자인 CSS 를 그대로 사용 — 인쇄 결과가 실제 계약서와 동일)
